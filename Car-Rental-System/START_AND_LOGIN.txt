┌───────────────────────────────────────────────────────────────────┐
│  ✅ WHAT HAPPENS BEHIND THE SCENES                                │
└───────────────────────────────────────────────────────────────────┘

  When you click Login:

  1️⃣  Frontend sends your 4 fields to backend
      POST → /admin/login
      {
        "fullname": "nana cute",
        "email": "cute@gmail.com",
        "phone": "0987654321",
        "password": "123456789"
      }

  2️⃣  Backend receives and validates
      ✓ Check all 4 fields are present

  3️⃣  Query MySQL database
      SELECT * FROM admin_accounts
      WHERE email = 'cute@gmail.com'

  4️⃣  Validate each field
      ✓ Fullname: "nana cute" = "nana cute" ✅
      ✓ Email: "cute@gmail.com" = "cute@gmail.com" ✅
      ✓ Phone: "0987654321" = "0987654321" ✅
      ✓ Password: check_password_hash(stored, input) ✅

  5️⃣  Create admin session
      session['admin'] = 'cute@gmail.com'
      session['admin_name'] = 'nana cute'

  6️⃣  Return success
      Redirect to admin dashboard ✅


┌───────────────────────────────────────────────────────────────────┐
│  🔧 TROUBLESHOOTING                                               │
└───────────────────────────────────────────────────────────────────┘

  Problem: "All fields are required" error
  ────────────────────────────────────────
  Solution: Make sure you entered ALL 4 fields
           • Don't leave any field empty
           • Check for hidden spaces


  Problem: "Invalid credentials" error
  ────────────────────────────────────
  Solution: One of your fields doesn't match
           • Full Name: nana cute (lowercase!)
           • Email: cute@gmail.com
           • Phone: 0987654321 (no dashes or spaces)
           • Password: 123456789 (exactly)


  Problem: Page won't load
  ─────────────────────────
  Solution: Make sure Flask server is running
           • Check terminal shows "Running on..."
           • Try restarting: python app.py


  Problem: Can't access localhost:5000
  ─────────────────────────────────────
  Solution: • Make sure Flask server is running
           • Try http://127.0.0.1:5000/admin/login
           • Check if port 5000 is blocked
