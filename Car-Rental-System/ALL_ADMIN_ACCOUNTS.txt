╔═══════════════════════════════════════════════════════════════════╗
║                  HOW TO ADD MORE ADMIN ACCOUNTS                   ║
╚═══════════════════════════════════════════════════════════════════╝

METHOD 1: Quick Add (Easiest!)
────────────────────────────────

1. Edit quick_add_admin.py
2. Change the NEW_ADMIN dictionary:

   NEW_ADMIN = {
       'fullname': 'Your Name',
       'email': 'your@email.com',
       'phone': '1234567890',
       'password': 'YourPassword'
   }

3. Run: python quick_add_admin.py
4. Done! ✅


METHOD 2: Interactive Add
──────────────────────────

1. Run: python add_admin.py
2. Enter details when prompted
3. Confirm
4. Done! ✅


METHOD 3: View All Admins
──────────────────────────

Run: python verify_admin.py

This shows all admin accounts in database
